# Data Structures, Algorithms & Problem Solving

This repository contains my solutions to programming, Data Structures & Algorithms (DSA), SQL, Pandas, and other problem-solving challenges.

Most solutions are practiced through [LeetCode](https://leetcode.com/) and automatically synchronized to this repository using [LeetSync](https://github.com/hzabala/LeetSync).

The repository serves as a structured record of my problem-solving practice, covering algorithms, data structures, databases, data manipulation, and multiple programming languages.
