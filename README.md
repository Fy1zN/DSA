This repository contains my solutions to Data Structures and Algorithms (DSA) problems. Solutions are solved on [LeetCode](https://leetcode.com/) and automatically synchronized to this repository using [LeetSync](https://github.com/hzabala/LeetSync).

## 🛠 Languages

- **C** — low-level execution mechanics and memory handling

## 🔄 Automation

New solutions are pushed automatically whenever a problem is solved on LeetCode, using **LeetSync**, which:

1. Detects a successful submission on LeetCode
2. Creates/updates the corresponding folder in this repo
3. Commits the solution with an auto-generated commit message
